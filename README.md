# IIT_BOMBAY_PLACEMENT
IIT Bombay student placement analysis using Python, Pandas, NumPy and Matplotlib
IIT Bombay Placement Analysis

Project Overview

A beginner-friendly Data Analytics project analyzing student placement data for IIT Bombay using Python.

Tools Used-

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis-

- Overall placement rate
- Branch-wise placement analysis
- Average and highest CTC
- Company-wise recruitment
- Sector-wise placement
- CGPA vs package analysis
- Coding score analysis
- Data visualization

Dataset-

This project uses a simulated dataset of 300 students for educational and analytical purposes. It is not official IIT Bombay placement data.
