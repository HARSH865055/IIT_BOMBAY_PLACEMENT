# Python Scripts

This folder contains Python scripts for IIT Bombay Placement Data Analysis.

## Scripts Included

1. data_generation.py
   - Generates simulated student placement data.

2. data_cleaning.py
   - Checks and cleans the dataset.

3. overall_placement_analysis.py
   - Calculates overall placement statistics.

4. branch_analysis.py
   - Analyzes branch-wise placements.

5. company_analysis.py
   - Analyzes company-wise recruitment.

6. salary_analysis.py
   - Analyzes salary distribution.

7. cgpa_analysis.py
   - Studies the relationship between CGPA and placements.

8. coding_analysis.py
   - Analyzes coding scores.

9. sector_analysis.py
   - Analyzes sector-wise placements.

10. correlation_analysis.py
    - Studies relationships between numerical variables.

Note: All analysis uses simulated data for educational purposes
