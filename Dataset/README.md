# Dataset

This folder contains the student placement dataset used in the IIT Bombay Placement Analysis project.

## Dataset Details
- Total Records: 300 simulated students
- Total Columns: 11
- Format: CSV

## Columns
1. Student_ID
2. Institute
3. Branch
4. CGPA
5. Coding_Score
6. Placement_Status
7. Company
8. Sector
9. Offers
10. Base_Salary_LPA
11. Total_CTC_LPA

## Note
This dataset is simulated for educational purposes and does not represent official IIT Bombay placement records.
